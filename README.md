# Cobrinha - Aula de Lógica

Este repositório faz parte da aula de Programação e Algoritmos (PA), do curso de Desenvolvimento de Jogos da Etec Dr. Carolino da Motta e Silva.

O objetivo deste material é usar o jogo da cobrinha como exercício prático para treinar lógica de programação com JavaScript.

## O que os alunos vão praticar

- leitura e organização de código
- uso de variáveis
- criação de funções
- atualização de estado do jogo
- desenho de elementos na tela com `canvas`
- movimentação com teclado
- raciocínio passo a passo para resolver problemas

## Arquivos deste projeto

- `index.html`: estrutura da página e estilos básicos
- `script.js`: ponto de partida da aula, com o início do código e um checklist do que será construído em sala

## Como usar

Abra o arquivo `index.html` no navegador ou use uma extensão como Live Server no VS Code.

## Importante

Neste momento, o `script.js` não está completo de propósito.

Ele foi preparado para ser desenvolvido durante a aula, junto com a turma, passo a passo.

## Sugestão para estudo

- leia os comentários antes de escrever código
- implemente uma etapa por vez
- teste o resultado a cada pequena mudança
- tente explicar com suas palavras o que cada variável e cada função fazem
